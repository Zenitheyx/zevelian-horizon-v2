# ZEVELIAN OS — Horizon Final

A compact CC:Tweaked OS for an Advanced Computer + Monitor + Advanced Peripherals.

## Install
wget https://raw.githubusercontent.com/Zenitheyx/zevelian-horizon/main/install.lua install
install Zenitheyx zevelian-horizon main
reboot

Default login: admin / zevelian

## Apps
MUSIC, WEB, CHAT, ENV, INV, REDSTONE, SETTINGS, SYSTEM, DIAG

Music supports direct DFPWM URLs when a CC:Tweaked Speaker is installed.
